# 🍸 CocktailPedia

An Android application that implements navigation and view structure for exploring cocktail recipes. Built with Kotlin and Jetpack Compose following Clean Architecture principles.

![Kotlin](https://img.shields.io/badge/Kotlin-7F52FF?style=for-the-badge&logo=kotlin&logoColor=white)
![Android](https://img.shields.io/badge/Android-3DDC84?style=for-the-badge&logo=android&logoColor=white)
![Jetpack Compose](https://img.shields.io/badge/Jetpack%20Compose-4285F4?style=for-the-badge&logo=jetpack-compose&logoColor=white)

---

## 📱 Features

- **Navigation Structure** - Multi-screen navigation with Jetpack Navigation Component
- **Clean Architecture** - Organized with data, domain, and presentation layers
- **Cocktail Browsing** - Explore cocktail recipes with a modern UI
- **Material Design 3** - Beautiful and consistent design language
- **Kotlin-first** - 100% Kotlin codebase

---

## 🛠️ Tech Stack

- **Kotlin** - Modern, concise programming language
- **Jetpack Compose** - Declarative UI framework
- **Navigation Component** - Type-safe navigation
- **Clean Architecture** - MVVM with separation of concerns
- **Gradle KTS** - Kotlin-based build configuration

---

## 🚀 Getting Started

### Prerequisites
- Android Studio (latest version)
- JDK 17 or higher

### Installation

```bash
git clone https://github.com/PedroGM80/CocktailPedia.git
cd CocktailPedia
./gradlew build
```

Open in Android Studio and run on your device or emulator.
